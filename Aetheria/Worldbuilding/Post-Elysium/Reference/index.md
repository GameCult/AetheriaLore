# Post-Elysium Reference

These notes describe the records, agreements, and classification codes that post-Elysium institutions use to make practical decisions involving altered reality. They explain how an office can consider contradictory evidence, how ports and insurers act within their separate powers, and how catalogues label weapons. These tools let institutions work with strange physics without publicly explaining everything that underlies it.
